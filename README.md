# Traffic-Aware Serverless LLM Inference

This project compares five GPU warm-state management policies for LLM
inference:

1. Always-On
2. Naive Serverless
3. Fixed Keep-Warm
4. Rule-Based Adaptive Keep-Warm
5. ML-Based Adaptive Keep-Warm
